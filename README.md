# QA Automation Project

End-to-end QA automation project covering UI testing, API testing, reporting and test automation practices.

## Technologies

- Python
- Selenium
- Pytest
- Postman
- Requests
- Pytest HTML
- Git
- GitHub

## UI Test Coverage

- Valid login
- Invalid login
- Empty username
- Empty password
- Add product to cart
- Remove product from cart
- Checkout
- Negative checkout scenarios
- Product sorting

## API Test Coverage

- GET all posts
- GET single post
- POST create post
- PUT update post
- DELETE post
- Negative API testing
- Status code validation
- Response body validation
